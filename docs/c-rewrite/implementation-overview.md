# Архитектура и совместимость mt-c

Оригинальный MagiTrickle написан на Go. **mt-c** — переписанный на C11
движок, созданный для уменьшения накладных расходов на роутерах с
ограниченными ресурсами.

**Основная ветка:** [`main`](https://github.com/dan0102dan/mt-c/tree/main).
В датированных отчётах Phase 0–9 сохранено прежнее название ветки
`claude/magitrickle-c-rewrite-phase-0-t7iwas` — это та же ветка до переименования.

## Что осталось совместимым

Цель переписывания — сохранить пользовательский формат конфигурации **YAML**,
существующий **HTTP API** и поведение при работе с **iptables/ipset**,
включая стандартные префиксы `MT_` для цепочек и `mt_` для множеств.
Детальные требования и проверки перечислены в
[контракте совместимости](compatibility-contract.md).
Сознательные отличия и принятые решения описаны в
[журнале решений](decisions.md).

## Что изменилось внутри

DNS-прокси использует событийный цикл `epoll` вместо рантайма Go и
сборщика мусора. Это сокращает накладные расходы на выполнение, но
практический эффект нужно оценивать по воспроизводимым тестам, а не
только по выбранному языку программирования.
